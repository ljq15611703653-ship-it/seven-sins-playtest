# Sin Squad source archive

This directory contains the Sin Squad / 牌桌游戏 project source archive: the earlier Godot version and the design documents that the current TypeScript game in [`../sin-squad-core/`](../sin-squad-core/) builds on.

## Included

- `sin-squad-godot/`: Godot project source, game rules and systems, content data, tutorial, tests, tools, original art source files, and project configuration.
- `sin-squad-design/`: design documents, execution specifications, content catalogs, review materials, and audit scripts.

## Running locally

Open `sin-squad-godot/project.godot` with Godot 4.x and run the project. `PLAY_GAME.bat` is provided for Windows.

## Archive notes

Generated Godot import/cache data (`.godot/`), test screenshots/evidence, temporary logs, and the generated `web-preview/` export are omitted from this source archive. The Godot web export that used to live in `sin-squad/` at the repository root was removed from `main`; it is kept at the `prototypes-archive-2026-09` tag.
